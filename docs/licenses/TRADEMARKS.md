# Provider logos

The provider logos in `app/src/main/res/drawable/ic_logo_*.xml` come from [Simple Icons](https://simpleicons.org) 16.35.0. Simple Icons releases its path data under CC0 1.0, but the logos themselves are trademarks of their owners:

| Drawable | Mark | Owner |
|---|---|---|
| `ic_logo_claude.xml` | Claude | Anthropic, PBC |
| `ic_logo_openai.xml` | OpenAI | OpenAI, L.L.C. |
| `ic_logo_gemini.xml` | Google Gemini | Google LLC |

The app shows each logo next to the provider's name only so you can tell which service a session used. This project isn't affiliated with, sponsored, or endorsed by any of these companies.
